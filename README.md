# Assignment 01: Five Stunning Places

A small five-page personal atlas.
Built with only basic HTML tags
(`<table>`, `<img>`, `<a>`, headings, `<p>`, `<div>`) and standard CSS —
no Flexbox, no Grid, no JavaScript — as required by the course.

## The five destinations

1. **Kyoto** — Japan
2. **Petra** — Jordan
3. **Banff** — Canada
4. **Santorini** — Greece
5. **Patagonia** — Chile & Argentina

Each page has five descriptive paragraphs, images, a table-based layout,
and a link back to the homepage, as required by the brief.

## Technologies used (as taught in class)

- HTML — only basic structural tags:
  `<html>`, `<head>`, `<body>`, `<div>`, `<table>`, `<tr>`, `<td>`,
  `<h1>`–`<h3>`, `<p>`, `<a>`, `<img>`, `<span>`, `<hr>`, `<br>`
- CSS — standard properties only, no Flexbox, no Grid, no JavaScript.
  Hover interactions use `:hover` and `transition` (pure CSS).
